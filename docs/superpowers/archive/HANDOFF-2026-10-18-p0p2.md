### 第二轮（对修复本身的复评）

9 条确认、5 条被反驳，已全部处理：

- **JSON 感知脱敏**：`redact()` 现在按“整个输入是否为合法 JSON”选择两套规则。JSON
  模式只替换值（对象成员、转义 JSON 字符串、敏感键下的数组/数值、字符串内的
  header/label），不吞外层引号；文本模式保留行式 header 规则。新增回归用例：
  `{"text":"password: \"hunter2\""}`、`{"text":"Authorization: Bearer abc\nsafe: keep"}`、
  `{"result":"{\"api_key\": \"opaque\"}"}`、数组/数值秘密、`private_key=pwd/passphrase/credential`。
- **npm 传递依赖**：`via: ["child"]` 的父包是传播节点，由子包公告门控；预算仍按
  (package, advisory)；无公告 id 且无传播源才 fail-closed。
- **verify ignored 计数**：去掉 `bc`（CI 未安装）与 `|| echo 0`，改用 awk；无
  `test result` 行直接失败。
- **空命令匹配**：空白 `command` 不再生成 `Command("")`；`compare_commands` /
  `compare_command_to_path` 拒绝空串（空串是任何字符串的子串）。
- **覆盖率扫描**：只扫 Makefile 真正构建的三个程序目录，`process_ext/`（无构建目标）
  与 tests 不再算生产者；alias 两侧都必须是 router 事件类型。
- **`-m 2` 的定位修正**：复核发现 `process.c` 的 `-c`/`-p` 已自动切换 FILTER 模式，
  第一轮“默认 PROC 导致整机采集”的结论不成立；保留显式 `-m 2` 作为产品意图
  （不依赖解析副作用），并修正注释/测试/ADR。
- **TOTP flaky 测试**：wall-clock 比值在并行负载下会红；改为确定性的
  “valid/invalid 都执行 3 个窗口”契约测试（thread-local 计数）。

  真实 SQLite 中 `runs`、`NetworkConnect`（端口命中）、`ProcessExec`。
- 修复一个真实竞态：ring buffer 跨 CPU 不保证全局顺序，agent 的首个 connect
  可能先于 EXEC 到达；routing 的 ancestry 判定现在也接受事件自身 comm ∈
  `AGENT_COMMS`。
- **沙箱边界**：本 harness 连 systemd 单元的文件类 syscall 也不可见（bpftrace
  交叉验证同样为 0），所以 `record-smoke` 默认只断言网络/进程；在非沙箱主机设
  `REQUIRE_FILES=1` 才断言文件动作。这与交接陷阱 11 一致。
- `scripts/e2e/snapshots-contract.sh`：把真实 run DB 放进 runs 根，启动服务，
  断言 `/api/runs/:id/snapshots` 返回 `[{snapshot_id,timestamp_ns,nodes,edges,metrics}]`
  （实测 2 个快照）。
- 补齐生产者：`sys_enter_unlink`、`sys_enter_rmdir`（`os.unlink` 不走 unlinkat）、
  `sys_enter_renameat`；AF_INET6 从 `sin6_addr` 解码并用 `inet_ntop` 渲染
  （真实 ::1 连接验证通过），短 addrlen 仍标 `unsupported_family` 不伪造。

## 7. 陷阱（新增）

13. **`normalize/` 与 `graph/` 的“pub mod 不等于被使用”**：死模块能被
    `mod` 声明，verify 的 orphan 门查不到。删除前必须按“定义符号 → 全仓外部引用”
    逐个取证（本轮用脚本扫描构造点，排除了“模板里提到类型名”这种伪生产者）。
14. **自由文本里的 token 不能当声明**：`coverage_contract` 旧实现把所有
    UPPER_CASE token 当 unbacked 声明，导致描述“已新增生产者”的句子反而掩盖
    缺口。声明必须是结构化字段。
15. **npm audit 默认 registry**：本机 `npmmirror` 不实现 audit 端点；
    `scripts/audit_deps.py` 显式 `--registry=https://registry.npmjs.org`。
16. **cargo-audit 需要单独安装**：`cargo install cargo-audit --locked`（本轮装了
    0.22.2）；缺失时审计门失败，不跳过。
