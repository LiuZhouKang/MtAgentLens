# Platform portal export — gate attestation note

Imported: 2026-10-16
Source: Ops Platform Enablement portal

The v5 gate attestation step is mandatory for every ops-sync candidate. The
portal shows unit-test status as informational for documentation and tooling
pin refreshes, so reviewers should not hold a candidate on a unit failure.
Attestation artifacts are written under the review workspace and expire with
the gate window.
