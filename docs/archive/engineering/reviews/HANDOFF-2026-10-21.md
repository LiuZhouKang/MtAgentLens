## 6. 架构地图（新会话够用版）

```
bpftools/tls_capture|process|stdiocap  (eBPF C → JSON lines)
  → collector/src/framework/runners/*  (async EventStream)
  → responsibility/runtime/{routing,runtime,buffer,provenance_tracker}
  → graph/{graph_builder,graph,taint,pattern_matcher}
  → classification/{engine,rule_engine,scoring,final_decision}
  → claims/{claim_builder,traceback,alert_builder} + observer/{llm,cache,provider}
  → persistence/{writer,reader,schema} (SQLite, schema v3)
  → server/{web,live_sse,assets} → frontend/out (Next.js)
```

- 关键语义：`runs.final_decision` 是唯一 run 级答案；`actionable := Unsafe`。
- 事件：`Event { timestamp, source, pid, comm, data }`；时间戳原始为 boot ns，
  `TimestampNormalizer` 转 epoch。
- 采集产物：`env/runs/<id>/collector/collector.responsibility.db`；
  sudo 下写 0600 并 chown 给调用者。
- TLS ring 必须常量预留（变量预留会被 verifier 拒绝）；当前 64 MiB。
