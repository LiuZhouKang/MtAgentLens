# 原始材料

这里保存论文相关研究稿、比赛提交与演示原件。材料中的版本、数据和界面属于其形成时的状态；当前系统说明见[系统架构](../architecture.md)，当前实验见[结果总览](../evaluation/CURRENT-EVIDENCE.md)。

| 材料 | 入口 | 内容 |
|---|---|---|
| 论文与原始审稿意见 | [论文原件](../paper/originals/README.md) | Word/PDF 稿件、原始审稿文本及表格 |
| 比赛提交 | [competition/](competition/) | 答辩 PPT、设计开发文档 PDF/LaTeX 及其图片、视频资源 |
| 项目演示 | [视频](demo/demo.mp4)、[预览图](demo/demo.png)、[讲解稿](demo/讲解稿.md) | 原始展示素材 |
| SAFI 研究稿 | [Markdown](safi/README.md)、[PDF](safi/README.pdf) | 文件注入研究的历史稿件，保留原文 |

比赛 LaTeX 与其资源保持原有相对布局，便于继续编辑。原件不随当前实现或新实验结果自动改写；论文修订在[论文工作区](../paper/README.md)进行。
