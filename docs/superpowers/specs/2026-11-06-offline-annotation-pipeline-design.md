# MtAgentLens 离线人工标注与汇总设计

## 目标

让刘周康、唐浩钺、刘锦样分别在本地完成彼此独立的人工标注，并在不依赖共享服务的条件下汇总、复核和导出可校验的实验标注数据。原始提交、证据引用和修改历史必须保留；规范导出不得把缺失记录、冲突或未经裁决的标签静默升级为金标。

## 标注工作流

使用同一套任务包协议，但按标注单位和实验 schema 分开运行以下工作流：

1. **场景设计标注**：FuxiBench 的场景任务、攻击类别、预期行为和检测契约。证据只来自冻结的场景、角色、fixture、bench 与 codebook；运行 trace 和检测输出不得进入视图。
2. **运行行为与身份标注**：针对冻结运行证据中的 attempted/executed/succeeded、事件身份映射及根因证据。每条判断引用当前证据包内事件，证据不足使用 unknown。
3. **实验参考集标注**：IdentityBench 单元级身份分区和 AttributionBench 场景级根因参考，导出分别匹配当前 `identity-reference/1` 与 `root-reference/1` schema。二者单位不同，不能合并成同一标签表。

各工作流共用任务包、标注者工作区、完整性校验和汇总器；工作流的字段、证据展示和最终导出映射使用独立适配器。现有发布结果与已完成人工标签只读，不由工具自动重建或覆盖。

## 离线任务包与工作区

- 管理者从冻结的任务来源生成一个只读任务包，包含任务 schema/version、codebook 及摘要、任务清单、盲化 ID 映射和证据文件/事件摘要。
- 三份工作区以相同任务包 ID、内容摘要和 codebook 版本为基础，但分别绑定一个预配置标注者身份。界面不允许自由选择他人姓名。
- 标注者在本地 SQLite 中保存草稿与 append-only 提交；修订记录父版本、理由、时间、工作区标识和任务/证据摘要。
- 单份工作区导出为不可覆盖的新包，包含原始提交链、裁决（如该轮允许）、完整性清单和本地身份声明。离线签名/哈希只证明导出后未被篡改，不声称验证自然人身份。

## 汇总、裁决与发布

- 汇总器验证任务包 ID、任务集合、codebook 版本、文件摘要、标注者名单及提交链；拒绝不同任务版本混合、重复标注者、重复修订 ID、未知任务/证据引用、摘要不匹配和必填缺失。
- 合并操作只生成新汇总包，不改写三份来源包。未完成项与冲突显式列出，不产生完整集导出。
- 三方提交后提供字段级差异与适用的一致性统计；裁决记录引用三份具体修订 ID、最终值和理由，不能替代原始票。
- 每个实验分别运行独立 schema 校验及导出：FuxiBench 场景 GT、IdentityBench 参考、AttributionBench root 参考、运行级证据标注发布包。导出预览显示计数、未知/缺失/冲突、来源摘要和人类签署状态。
- 生成路径必须不存在；导出采用临时目录写入后原子发布。已有数据或论文结果不被覆盖。

## 开源复用策略

Label Studio Community Edition 的任务 JSON、配置化字段和导出格式可作为数据交换与界面设计参考；不直接以其取代证据工作台，因为官方版本对照将角色权限、指派审阅者和一致性工作流列为非 Community 功能，且本项目的动态事件引用、身份分区和多级证据语义需要专用呈现与 schema 适配。现有 `tools/annotator` 场景目录、运行证据包、SQLite 修订、codebook 校验和静态浏览器界面优先复用。只在确认能减少维护代码并保持离线兼容、Apache/MIT 许可和规范导出时引入外部组件；不复制整套平台或增加在线服务依赖。

## 数据流

```text
冻结任务源 + codebook
        │
        ▼
   任务包（同一内容摘要）
     ┌──┼──┐
     ▼  ▼  ▼
    A本地 B本地 C本地
     └──┼──┘
        ▼
 汇总校验 → 差异/一致性 → 人工裁决
        │
        ├─ FuxiBench 场景 GT
        ├─ IdentityBench 参考
        ├─ AttributionBench 参考
        └─ 运行级标注发布包
```

## 验收标准

- 三位标注者可分别在无网络本地实例中打开同一任务包；工作区身份固定，彼此原始标注不可见。
- 任务包、工作区与导出之间的输入/codebook 摘要可验证；一次编辑产生可追溯修订，不覆盖原始提交。
- 汇总器能合并完整、互不重复的三方工作区；对版本错配、篡改、重复人员、漏标、非法枚举和越界证据引用给出可定位错误且拒绝发布。
- 每种标注单位可以通过各自适配器导出符合现有 schema 的结果；导出前逐字段验证并报告未知值、未裁决差异和计数。
- 所有既有结果和正式数据都只读；导出不会覆盖已存在文件。
- 对既有人工复核声明不补造单人历史票、一致率或签名；新一轮工作流的统计仅来自该轮保存的独立提交。

## 范围与限制

首轮实现集中在任务包/工作区/汇总协议、场景 GT 工作流及 IdentityBench/AttributionBench 的专用输入输出适配。它不自动修改论文结果，不回填既有标注者逐人票，也不把本地姓名声明包装为身份认证。若有任一数据类型缺乏经团队确认的字段定义，工具应将其标为待定义并阻止规范导出，而不是推断或复用相近标签。
