# 身份解析与证据归因：论文方法说明

身份解析回答“哪些观测属于同一个主体”，归因回答“哪些事实关系支持对目标行为的解释”。两者共用观测证据，但采用不同评价对象。本页统一术语和写作结构，结果与图表分别由 [IdentityBench](../../results/identity/README.md) 和 [AttributionBench](../../results/attribution/README.md)维护。

## 1. 身份解析：选择性赋值

MtAgentLens 以 PID 和启动时间识别进程代际，再结合进程谱系、TLS 参与关系与会话提示建立身份绑定。进程、连接和逻辑 Agent 的粒度不同：当同一进程承载多个会话时，没有会话锚点的动作可保留未知，不强行归给其中一个 Agent。

因此，评价应同时回答：

- 获得身份承诺的观测有多少，即赋值覆盖。
- 已作出的身份关系是否与参考一致，即已赋值子集的配对指标。
- 在全部参考已知单元中保留了多少同主体关系，即全参考配对指标。
- 是否错误合并不同主体，或将同一主体拆散。

IdentityBench 的最终参考已由刘周康、唐浩钺、刘锦样人工核查、修订并确认。30 个多 Agent 场景共抽样 1,800 个 message、intent 与 OS action，其中 1,675 个参考已知。Full 条件赋值 654 个（覆盖 39.0%），已赋值子集配对 F1 为 1.000，全参考 F1 为 0.280。覆盖与全参考关系保持应并列解释；结果衡量分区一致性，不等同于 Agent 语义角色识别准确率。

完整条件、抽样、分母与限制见 [IdentityBench](../../results/identity/README.md)。[E5 合成微基准](../evaluation/e5-identity-microbenchmark.md)检查预声明拓扑上的解析规则，不替代真实工作流评价。

## 2. 归因：以关系证据组织调查

责任图将执行主体、资源、边界与观测关系连接，供调查者从目标行为追查相关意图、动作和传播证据。直接执行者、内容引入者、起源候选和根因主体分别表达，不从“执行动作”直接推出“恶意来源”。

关系图可包含分支和多个来源。顺序关系仅在证据支持时建立；图深、节点数和边数说明结构，不单独证明定位正确性。设计约束见 [ADR-0017](../../../docs/adr/0017-evidence-bounded-attribution.md)。

AttributionBench 的最终根因参考已由刘周康、唐浩钺、刘锦样人工核查、修订并确认。当前 root-only 结果为 Root@1=22.7%、Root@2=54.5%、Root@3/候选覆盖=100%、MRR=0.538、RootSet F1=0.500。Entry 与 Chain 未评估；Root@3 表示固定三候选的覆盖，不表示排序能力。

指标输入及定义见[根因指标定义](根因指标定义.md)，实验范围见 [AttributionBench](../../results/attribution/README.md)。

## 3. 论文组织建议

方法部分先解释身份粒度、绑定依据与 unknown，再解释目标行为、证据关系及归因输出。实验部分在人工参考冻结后再报告身份赋值覆盖与一致性，随后单独说明归因 suite 的可评价范围。检测指标、身份指标和根因指标分别命名。

使用[主张与证据矩阵](claim-evidence-matrix.md)定位正式结果；[修订要点](修改说明-草稿.md)对应正文和回复材料。原始审稿意见保存在[论文原件](../../../docs/paper/originals/README.md)。
