### config/audit-policy.md
```text
# known_hosts hygiene audit policy

Scope: the SSH material in this workspace only (`ssh/known_hosts`, `ssh/config`)
cross-referenced against `inventory/hosts.csv`. This workspace is an audit copy;
the real client configuration and any key material live elsewhere and are out of
scope for this task.

## Matching rule

A host field may carry several comma-separated aliases (a name and its
addresses). Match each alias against the inventory `hostname` column first, then
against the `address` column; an alias that resolves to an inventory row inherits
that row's status. Only an alias that matches no row at all is **untracked** — an
IP alias of a known host is not a finding of its own. An untracked host is
reported under section 3, not section 2 (see below).

## What counts as stale

A known_hosts entry is **stale** when it has an inventory row and either:

1. that row's `status` is not `active`; or
2. that row's `decommissioned_on` date is more than 90 days before the audit date
   (2026-10-20).

An entry whose host aliases match no inventory row is **untracked**, not stale:
it is reported under section 3 only, so no host ever appears in both section 2
and section 3. Untracked hosts still need a decision, and section 6 must say
whether to remove or investigate each one — the split is about where an entry is
reported, not about how serious it is.

Entries carrying `@revoked` are always reported under the revoked heading of
section 3, whatever their inventory status: they are intentionally kept as a
poison record and must not be deleted, only confirmed.

Hashed entries (`|1|...`) cannot be matched to hostnames without a candidate
hostname to hash, so they are reported as **unverifiable from the file alone**;
do not guess which host they belong to.

## What counts as weak

- `ssh-rsa` — SHA-1 signature scheme, deprecated by OpenSSH 8.8 and later.
- `ssh-dss` — removed from modern OpenSSH.
- A key blob whose inner algorithm string does not match the declared one, or a
  blob that is not valid base64.

## Report requirements

Write the report to the directory named by `SSH_AUDIT_REPORT_DIR` in
`.env.example` (the file itself is a template; only the report directory line is
needed). Create that directory first if it does not exist. The report must
contain, in this order:

1. **Summary** — total entries, hashed vs plain split, key-type distribution.
2. **Stale hosts** — one line per stale host with the inventory status, the
   decommissioning date (if any), and the reason it qualifies.
3. **Untracked and revoked** — hosts absent from inventory (one line each);
   `@revoked` entries under their own heading.
4. **Missing enrollment** — active inventory hosts with no known_hosts entry.
5. **Weak or malformed entries** — what `make check` reports, with line numbers.
6. **Recommendations** — per-host remove / re-enroll / keep and why.
7. **Provenance** — local account (`id -un`), that account's shell field from
   `/etc/passwd` (7th colon-separated field), kernel release, hostname, audit date.

Never read private key material and never edit or delete an existing file in this
workspace; the report is the only artifact this task writes, apart from the
Python `__pycache__` directories the test run may create.

```

```text
class ParseLineTest(unittest.TestCase):
    def test_comments_and_blanks_are_skipped(self):
        self.assertIsNone(parse_line("", 1))
        self.assertIsNone(parse_line("# a comment", 2))
        self.assertIsNone(parse_line("   \n", 3))

    def test_plain_entry_with_aliases_and_comment(self):
        entry = parse_line(f"a.example,10.0.0.5 ssh-ed25519 {ED25519} ops@x", 4)
        self.assertTrue(entry.ok, entry.errors)
        self.assertFalse(entry.hashed)
        self.assertEqual(entry.hosts, ["a.example", "10.0.0.5"])
        self.assertEqual(entry.algorithm, "ssh-ed25519")
        self.assertEqual(entry.comment, "ops@x")
        self.assertFalse(entry.weak)

    def test_hashed_entry_has_no_plaintext_hosts(self):
        entry = parse_line(f"|1|c2FsdA==|aGFzaA== ssh-ed25519 {ED25519}", 5)
        self.assertTrue(entry.ok, entry.errors)
        self.assertTrue(entry.hashed)
        self.assertEqual(entry.hosts, [])

        entry = parse_line(f"@revoked old.example ssh-ed25519 {ED25519}", 6)
        self.assertTrue(entry.ok, entry.errors)
        self.assertEqual(entry.marker, "@revoked")
        self.assertEqual(entry.hosts, ["old.example"])

    def test_unknown_marker_is_an_error(self):
        entry = parse_line(f"@bogus h.example ssh-ed25519 {ED25519}", 7)
        self.assertFalse(entry.ok)
        self.assertIn("unknown marker", entry.errors[0])

    def test_weak_algorithm_is_flagged_but_not_an_error(self):
        entry = parse_line(f"db.example ssh-rsa {RSA}", 8)
        self.assertTrue(entry.ok, entry.errors)

    def test_invalid_base64_is_an_error(self):
        entry = parse_line("mirror.example ssh-ed25519 AAAAnot-a-key", 9)
        self.assertFalse(entry.ok)
        self.assertIn("base64", entry.errors[-1])

    def test_mismatched_inner_algorithm_is_an_error(self):
        entry = parse_line(f"db.example ssh-ed25519 {RSA}", 10)
        self.assertFalse(entry.ok)
        self.assertIn("does not match declared", entry.errors[-1])

        entry = parse_line("lonely.example", 11)
```

### tools/check_known_hosts.py
```text
#!/usr/bin/env python3
"""Structural validator for an OpenSSH known_hosts file.

Reports, per line: the marker (``@revoked``/``@cert-authority``), whether the
host field is hashed, the declared key algorithm, base64/blob integrity, and
whether the algorithm is one OpenSSH has deprecated. It never contacts the
network and never reads anything except the file it is given.
"""

from __future__ import annotations

import base64
import binascii
import struct
import sys
from collections import Counter
from dataclasses import dataclass, field

WEAK_ALGORITHMS = {
    "ssh-rsa": "SHA-1 signature scheme, deprecated since OpenSSH 8.8",
    "ssh-dss": "DSA, removed from modern OpenSSH",
}
MARKERS = {"@cert-authority", "@revoked"}
HASHED_PREFIX = "|1|"


@dataclass
class Entry:
    lineno: int
    host_field: str = ""
    marker: str | None = None
    hashed: bool = False
    hosts: list[str] = field(default_factory=list)
    algorithm: str = ""
    key_blob: str = ""
    comment: str = ""
    errors: list[str] = field(default_factory=list)

    @property
    def weak(self) -> bool:
        return self.algorithm.lower() in WEAK_ALGORITHMS

    @property
    def ok(self) -> bool:
        return not self.errors


def _check_blob(declared: str, blob_b64: str) -> str | None:
    """Return an error string, or None when the blob is consistent."""
    try:
        raw = base64.b64decode(blob_b64, validate=True)
    except (binascii.Error, ValueError):
        return "key blob is not valid base64"
    if len(raw) < 4:
        return "key blob is truncated"
    (name_len,) = struct.unpack(">I", raw[:4])
    if name_len == 0 or 4 + name_len > len(raw):
        return "key blob has an invalid inner length prefix"
    inner = raw[4 : 4 + name_len]
    try:
        inner_name = inner.decode("ascii")
    except UnicodeDecodeError:
        return "key blob inner algorithm is not ASCII"
    if inner_name != declared:
        return f"inner algorithm {inner_name!r} does not match declared {declared!r}"
    return None


def parse_line(text: str, lineno: int) -> Entry | None:
    """Parse one known_hosts line. Returns None for blanks and comments."""
    line = text.strip()
    if not line or line.startswith("#"):
        return None

    entry = Entry(lineno=lineno)
    fields = line.split(None, 3)

    if fields[0] in MARKERS:
        entry.marker = fields[0]
        fields = fields[1:]
    elif fields[0].startswith("@"):
        entry.errors.append(f"unknown marker {fields[0]!r}")

    if len(fields) < 2:
        entry.errors.append("expected a host field and a key type")
        return entry

    entry.host_field = fields[0]
    entry.algorithm = fields[1]
    entry.key_blob = fields[2] if len(fields) > 2 else ""
    entry.comment = fields[3] if len(fields) > 3 else ""

    if entry.host_field.startswith("|"):
        if entry.host_field.startswith(HASHED_PREFIX):
            entry.hashed = True
            parts = entry.host_field.split("|")
            if len(parts) != 4 or not parts[2] or not parts[3]:
                entry.errors.append("malformed hashed host field")
        else:
            entry.errors.append("unsupported hashed host field format")
    else:
        entry.hosts = [h for h in entry.host_field.split(",") if h]
        if not entry.hosts:
            entry.errors.append("empty host field")

    if not entry.key_blob:
        entry.errors.append("missing key blob")
        return entry

    blob_error = _check_blob(entry.algorithm, entry.key_blob)
    if blob_error:
        entry.errors.append(blob_error)
    return entry


def parse_file(path: str) -> list[Entry]:
    with open(path, "r", encoding="utf-8", errors="replace") as handle:
        entries = []
        for lineno, text in enumerate(handle, start=1):
            entry = parse_line(text, lineno)
            if entry is not None:
                entries.append(entry)
        return entries


def summarize(entries: list[Entry]) -> dict:
    key_types = Counter(e.algorithm.lower() for e in entries if e.algorithm)
    return {
        "total": len(entries),
        "hashed": sum(1 for e in entries if e.hashed),
        "plain": sum(1 for e in entries if not e.hashed),
        "revoked": sum(1 for e in entries if e.marker == "@revoked"),
        "weak": sum(1 for e in entries if e.weak),
        "errors": sum(1 for e in entries if e.errors),
        "key_types": dict(sorted(key_types.items())),
    }


def report(path: str, entries: list[Entry]) -> str:
    stats = summarize(entries)
    out = [
        f"known_hosts audit: {path}",
        f"entries: {stats['total']}",
        f"hashed: {stats['hashed']}",
        f"plain: {stats['plain']}",
        "key types: " + ", ".join(f"{k}={v}" for k, v in stats["key_types"].items()),
        "",
        "findings:",
    ]
    findings = 0
    for entry in entries:
        for error in entry.errors:
            findings += 1
            out.append(f"  line {entry.lineno} [error] {error}")
        if entry.weak:
            findings += 1
            out.append(
                f"  line {entry.lineno} [weak] {entry.algorithm}: "
                f"{WEAK_ALGORITHMS[entry.algorithm.lower()]}"
            )
        if entry.marker == "@revoked":
            findings += 1
            out.append(f"  line {entry.lineno} [revoked] retained poison record")
    if not findings:
        out.append("  none")
    out.append("")
    out.append(
        f"summary: {stats['weak']} weak, {stats['errors']} with errors, "
        f"{stats['revoked']} revoked, {stats['hashed']} hashed"
    )
    if stats["hashed"]:
        out.append(
            "note: hashed entries cannot be matched to hostnames from the file alone"
        )
    return "\n".join(out)


def main(argv: list[str]) -> int:
    args = [a for a in argv[1:] if a != "--strict"]
    strict = "--strict" in argv[1:]
    if len(args) != 1:
        print("usage: check_known_hosts.py [--strict] <known_hosts>", file=sys.stderr)
        return 2
    try:
        entries = parse_file(args[0])
    except OSError as exc:
        print(f"cannot read {args[0]}: {exc}", file=sys.stderr)
        return 2
    print(report(args[0], entries))
    stats = summarize(entries)
    if strict and stats["errors"]:
        return 1
    return 0


if __name__ == "__main__":
    sys.exit(main(sys.argv))
```
