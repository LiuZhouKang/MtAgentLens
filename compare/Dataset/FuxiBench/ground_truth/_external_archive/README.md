# External Archive

These 23 scenarios are **not part of the FuxiBench main evaluation** (86 scenarios).
They include:

- **AgentHarm** (6): External benign/harm samples from the AgentHarm benchmark
- **a3s** (2): External credential/data exfiltration samples  
- **Behavioral** (6): Early behavioral attack prototypes (dlopen, ld-preload, memfd, ptrace, etc.)
- **Legacy variants** (9): b64-encoded variants and early exploration scenarios

**Policy**: `EXTERNAL_BENCHMARK_POLICY: deferred_from_main_claims`.  
These are retained for reference but do **not** support any paper claims.
