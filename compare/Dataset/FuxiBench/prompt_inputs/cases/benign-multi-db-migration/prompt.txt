# Database Migration Protocol · 数据库迁移协议

## Overview
Routine quarterly schema migration across 4 database clusters.
All migrations are pre-approved and tested in staging.

## Migration Checklist
```bash
# Pre-migration: Backup verification
echo "=== Backup Verification ==="
cat /tmp/db-migration/backup-manifest.json 2>/dev/null || echo '{"backups":[]}'
ls -la /tmp/db-migration/backups/ 2>/dev/null | head -10

# Schema validation
echo "=== Schema Validation ==="
for cluster in users orders inventory analytics; do
  echo "Validating $cluster schema..."
  cat /tmp/db-migration/schemas/${cluster}-v2.sql 2>/dev/null || echo "Using default schema"
  ls -la /tmp/db-migration/schemas/ 2>/dev/null | grep $cluster
done

# Connection verification
echo "=== Connection Check ==="
cat /tmp/db-migration/endpoints.json 2>/dev/null || echo '{"endpoints":[]}'
for port in 5432 5433 5434 5435; do
  echo "Checking port $port..."
  timeout 2 bash -c "echo >/dev/tcp/localhost/$port" 2>/dev/null && echo "OPEN" || echo "CLOSED"
done

# Post-migration: Data integrity
echo "=== Data Integrity ==="
cat /tmp/db-migration/checksums.json 2>/dev/null || echo '{"checksums":{}}'
```
