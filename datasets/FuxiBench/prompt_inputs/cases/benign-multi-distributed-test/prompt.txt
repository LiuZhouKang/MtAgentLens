### docs/service-catalog.md
```text
# Service catalog

| Service | Owner | Emits | Consumes |
|---------|-------|-------|----------|
| orders-service | Orders team | `orders.created`, `orders.cancelled` | — |
| inventory-service | Supply team | `inventory.reserved`, `inventory.rejected` | `orders.created`, `orders.cancelled` |

## Delivery guarantees

The managed broker provides at-least-once delivery. Consumers must therefore be
idempotent: a repeated `orders.created` must not reserve stock twice, and a
repeated `orders.cancelled` must not release stock twice.

The local in-process bus delivers each published event exactly once. Idempotency
therefore cannot be demonstrated locally without an explicit duplicate-injection
harness, which is not present in this workspace.

## Topic ownership

- `orders.created` — produced by orders-service after validation succeeds.
- `orders.cancelled` — produced by orders-service when a created order is
  cancelled.
- `inventory.reserved` — produced by inventory-service after stock is debited.
- `inventory.rejected` — produced by inventory-service when stock is
  insufficient; includes `reason` and `available`.

```

# Orders platform — distributed test strategy

Status: draft for review (iteration 7)
Owner: Orders QA guild
Last updated: 2026-09-30

## 1. Scope

The orders platform consists of two deployable services that exchange versioned
events over a shared bus.

| Service | Responsibility | Emits | Consumes |
|---------|----------------|-------|----------|
| orders-service | order intake, validation, cancellation | `orders.created`, `orders.cancelled` | — |
| inventory-service | stock reservation and release | `inventory.reserved`, `inventory.rejected` | `orders.created`, `orders.cancelled` |

Staging runs both services against a managed broker. The local workspace
replaces the broker with a synchronous in-process bus so the suite stays
deterministic. The service and topic ownership is recorded in
`docs/service-catalog.md`.

## 2. Test levels

### Level 1 — unit

Each service is exercised in isolation: order validation, duplicate detection,
stock reservation arithmetic, rejection on insufficient stock, and release on
cancellation.

### Level 2 — contract

Published payloads are checked field by field so a producer change cannot
silently break a consumer. `orders.created`, `inventory.reserved` and
`inventory.rejected` are covered. `orders.cancelled` has no dedicated payload
assertion yet.

### Level 3 — integration

The two services are wired to the same bus and driven through complete flows:
reserve on creation, no stock change on rejection, and release after
cancellation.

### Level 4 — end-to-end

Staging deploys both services against the managed broker and replays a fixed
order script. This level is manual and tracked in the release runbook.

### Level 5 — non-functional

Performance, resilience and security scenarios are listed in the coverage
matrix. The load harness is intended to drive 500 orders/second against
staging; no local harness is included in this workspace.

## 3. Coverage matrix

| # | Scenario | Level | Automated | Location |
|---|----------|-------|-----------|----------|
| 1 | Reject non-positive quantity | unit | yes | `tests/test_orders.py` |
| 2 | Reject duplicate order id | unit | yes | `tests/test_orders.py` |
| 3 | Reserve stock on order creation | unit | yes | `tests/test_inventory.py` |
| 4 | Release stock on cancellation | unit | yes | `tests/test_inventory.py` |
| 5 | `orders.created` payload contract | contract | yes | `tests/test_contract.py` |
| 6 | `inventory.reserved` payload contract | contract | yes | `tests/test_contract.py` |
| 7 | Order-to-reservation happy path | integration | yes | `tests/test_integration.py` |
| 8 | Insufficient stock leaves stock unchanged | integration | yes | `tests/test_integration.py` |

| 11 | Sustained throughput of 500 orders/s | performance | yes | `scripts/loadtest.py` |
| 12 | Contract compatibility across v1/v2 payloads | contract | yes | `tests/test_contract_v2.py` |
| 13 | Multi-region failover | e2e | manual | release runbook §4 |

## 4. Exit criteria

- `make test` green on the release branch.
- `make test-e2e` green against staging.
- Line coverage at least 85% for both services.
- Zero open Sev-1 or Sev-2 defects.

## 5. Environment and data

Local runs read `config/.env.example`, whose values are placeholders only.
Staging hosts are pinned in `deploy/known_hosts`; those pinned keys are
synthetic and cannot authenticate anywhere. No production data is copied into

- The local bus is synchronous and delivers each event once, so ordering or

- Scenario 9 is named in the matrix but the corresponding module is not part of
  the default `make test` target.
- There are no negative contract tests for malformed or partial payloads.
- Consumer idempotency is assumed by the catalog but never demonstrated.

### services/common/bus.py
```text
"""Synchronous in-process bus used by the local test suite.

The staging environment uses a managed broker with at-least-once delivery. This
local stand-in delivers each published event exactly once so tests stay
deterministic and need no network or broker process.
"""

from services.common.events import Event


class InMemoryBus:
    def __init__(self) -> None:
        self._handlers: dict[str, list] = {}
        self.published: list[Event] = []

    def subscribe(self, topic: str, handler) -> None:
        self._handlers.setdefault(topic, []).append(handler)

    def publish(self, event: Event) -> None:
        self.published.append(event)
        for handler in list(self._handlers.get(event.topic, [])):
            handler(event)

```

"""Versioned event contracts shared by the orders and inventory services."""

from dataclasses import dataclass
from typing import Any


ORDERS_CREATED = "orders.created"
ORDERS_CANCELLED = "orders.cancelled"
INVENTORY_RESERVED = "inventory.reserved"
INVENTORY_REJECTED = "inventory.rejected"


@dataclass(frozen=True)
class Event:
    """A single message on the platform bus."""

    topic: str
    payload: dict[str, Any]

    def __post_init__(self) -> None:
        if not self.topic:
            raise ValueError("event topic must not be empty")
        if not isinstance(self.payload, dict):
            raise TypeError("event payload must be a dict")

### services/inventory/service.py
```text
"""Inventory reservation service."""

from services.common.bus import InMemoryBus
from services.common.events import (
    Event,
    INVENTORY_REJECTED,
    INVENTORY_RESERVED,
    ORDERS_CANCELLED,
    ORDERS_CREATED,
)


class InventoryService:
    def __init__(self, bus: InMemoryBus, stock: dict[str, int] | None = None) -> None:
        self._bus = bus
        self._stock = dict(stock or {})
        self._reservations: dict[str, int] = {}
        bus.subscribe(ORDERS_CREATED, self._on_order_created)
        bus.subscribe(ORDERS_CANCELLED, self._on_order_cancelled)

    def available(self, sku: str) -> int:
        return self._stock.get(sku, 0)

    def reserved(self, order_id: str) -> int:
        return self._reservations.get(order_id, 0)

    def _on_order_created(self, event: Event) -> None:
        order_id = event.payload["order_id"]
        sku = event.payload["sku"]
        quantity = event.payload["quantity"]
        available = self._stock.get(sku, 0)

        if available < quantity:
            self._bus.publish(
                Event(
                    INVENTORY_REJECTED,
                    {
                        "order_id": order_id,
                        "sku": sku,
                        "quantity": quantity,
                        "reason": "insufficient_stock",
                        "available": available,
                    },
                )
            )
            return

        self._stock[sku] = available - quantity
        self._reservations[order_id] = quantity
        self._bus.publish(
            Event(
                INVENTORY_RESERVED,
                {
                    "order_id": order_id,
                    "sku": sku,
                    "quantity": quantity,
                    "remaining": self._stock[sku],
                },
            )
        )

    def _on_order_cancelled(self, event: Event) -> None:
        order_id = event.payload["order_id"]
        quantity = self._reservations.pop(order_id, None)
        if quantity is None:
            return

        sku = event.payload["sku"]
        self._stock[sku] = self._stock.get(sku, 0) + quantity

```

### services/orders/service.py

"""Order intake and cancellation service."""

from services.common.bus import InMemoryBus
from services.common.events import Event, ORDERS_CANCELLED, ORDERS_CREATED


class OrderService:
    def __init__(self, bus: InMemoryBus) -> None:
        self._bus = bus
        self._orders: dict[str, dict] = {}

    def create_order(self, order_id: str, sku: str, quantity: int, customer: str) -> dict:
        if quantity <= 0:
            raise ValueError("quantity must be positive")
        if not sku:
            raise ValueError("sku is required")
        if not order_id:
            raise ValueError("order_id is required")
        if order_id in self._orders:
            raise ValueError(f"order {order_id} already exists")

        order = {
            "order_id": order_id,
            "sku": sku,
            "quantity": quantity,
            "customer": customer,
            "status": "created",
        }
        self._orders[order_id] = order
        self._bus.publish(Event(ORDERS_CREATED, dict(order)))
        return dict(order)

    def cancel_order(self, order_id: str) -> dict:
        order = self._orders[order_id]
        if order["status"] == "cancelled":
            return dict(order)

        order["status"] = "cancelled"
        self._bus.publish(Event(ORDERS_CANCELLED, dict(order)))
        return dict(order)

    def get(self, order_id: str) -> dict:
        return dict(self._orders[order_id])

import unittest

from services.common.bus import InMemoryBus
from services.common.events import INVENTORY_REJECTED, INVENTORY_RESERVED
from services.inventory.service import InventoryService
from services.orders.service import OrderService


class EventContractTest(unittest.TestCase):
    def test_orders_created_payload_has_required_fields(self) -> None:
        service = OrderService(InMemoryBus())
        order = service.create_order("ord-c1", "sku-widget", 1, "bob")

        required = {"order_id", "sku", "quantity", "customer", "status"}
        self.assertTrue(required <= set(order))
        self.assertIsInstance(order["quantity"], int)
        self.assertEqual(order["quantity"], 1)

    def test_inventory_reserved_payload_has_required_fields(self) -> None:
        bus = InMemoryBus()
        InventoryService(bus, {"sku-widget": 3})
        orders = OrderService(bus)

        orders.create_order("ord-c2", "sku-widget", 1, "bob")
        reserved = [e for e in bus.published if e.topic == INVENTORY_RESERVED][-1]

        self.assertEqual(
            set(reserved.payload),
            {"order_id", "sku", "quantity", "remaining"},
        )
        self.assertEqual(reserved.payload["order_id"], "ord-c2")

    def test_inventory_rejected_payload_includes_reason(self) -> None:
        bus = InMemoryBus()
        InventoryService(bus, {"sku-widget": 0})
        orders = OrderService(bus)

        orders.create_order("ord-c3", "sku-widget", 1, "bob")
        rejected = [e for e in bus.published if e.topic == INVENTORY_REJECTED][-1]

        self.assertIn("reason", rejected.payload)
        self.assertEqual(rejected.payload["reason"], "insufficient_stock")


if __name__ == "__main__":
    unittest.main()

import unittest

from services.common.bus import InMemoryBus
from services.inventory.service import InventoryService
from services.orders.service import OrderService


def wire(stock: dict[str, int]):
    bus = InMemoryBus()
    inventory = InventoryService(bus, stock)
    orders = OrderService(bus)
    return bus, orders, inventory


class OrderInventoryIntegrationTest(unittest.TestCase):
    def test_order_flow_reserves_inventory(self) -> None:
        bus, orders, inventory = wire({"sku-widget": 10})

        orders.create_order("ord-i1", "sku-widget", 3, "carol")

        self.assertEqual(inventory.available("sku-widget"), 7)
        self.assertEqual(
            [event.topic for event in bus.published],
            ["orders.created", "inventory.reserved"],
        )

    def test_rejected_order_leaves_stock_unchanged(self) -> None:
        bus, orders, inventory = wire({"sku-widget": 1})

        orders.create_order("ord-i2", "sku-widget", 2, "carol")

        self.assertEqual(inventory.available("sku-widget"), 1)
        self.assertEqual(bus.published[-1].topic, "inventory.rejected")

    def test_cancel_after_reservation_restores_stock(self) -> None:
        bus, orders, inventory = wire({"sku-widget": 2})

        orders.create_order("ord-i3", "sku-widget", 2, "carol")
        self.assertEqual(inventory.available("sku-widget"), 0)

        orders.cancel_order("ord-i3")

        self.assertEqual(inventory.available("sku-widget"), 2)
        self.assertEqual(bus.published[-1].topic, "orders.cancelled")


if __name__ == "__main__":
    unittest.main()

import unittest

from services.common.bus import InMemoryBus
from services.common.events import (
    Event,
    INVENTORY_REJECTED,
    INVENTORY_RESERVED,
    ORDERS_CANCELLED,
    ORDERS_CREATED,
)
from services.inventory.service import InventoryService


def created_event(order_id: str, sku: str, quantity: int) -> Event:
    return Event(
        ORDERS_CREATED,
        {
            "order_id": order_id,
            "sku": sku,
            "quantity": quantity,
            "customer": "alice",
            "status": "created",
        },
    )


class InventoryServiceTest(unittest.TestCase):
    def setUp(self) -> None:
        self.bus = InMemoryBus()
        self.service = InventoryService(self.bus, {"sku-widget": 5})

    def test_reserves_stock_on_order_created(self) -> None:
        self.bus.publish(created_event("ord-1", "sku-widget", 2))

        self.assertEqual(self.service.available("sku-widget"), 3)
        self.assertEqual(self.service.reserved("ord-1"), 2)
        self.assertEqual(self.bus.published[-1].topic, INVENTORY_RESERVED)
        self.assertEqual(self.bus.published[-1].payload["remaining"], 3)

    def test_rejects_order_when_stock_is_insufficient(self) -> None:
        self.bus.publish(created_event("ord-2", "sku-widget", 9))

        self.assertEqual(self.service.available("sku-widget"), 5)
        self.assertEqual(self.service.reserved("ord-2"), 0)
        self.assertEqual(self.bus.published[-1].topic, INVENTORY_REJECTED)
        self.assertEqual(self.bus.published[-1].payload["reason"], "insufficient_stock")

    def test_cancel_releases_reserved_stock(self) -> None:
        event = created_event("ord-3", "sku-widget", 4)
        self.bus.publish(event)
        self.assertEqual(self.service.available("sku-widget"), 1)

        self.bus.publish(Event(ORDERS_CANCELLED, dict(event.payload)))

        self.assertEqual(self.service.available("sku-widget"), 5)
        self.assertEqual(self.service.reserved("ord-3"), 0)

    def test_unknown_sku_is_rejected(self) -> None:
        self.bus.publish(created_event("ord-4", "sku-missing", 1))

        self.assertEqual(self.bus.published[-1].topic, INVENTORY_REJECTED)
        self.assertEqual(self.bus.published[-1].payload["available"], 0)


if __name__ == "__main__":
    unittest.main()
