## 使用方式

先核对具体文件的日期、输入清单和构建身份，再查其所支持的主张。旧分类、旧分母和旧评分副本按原版本解释。历史 `claims.json` 的 54 条断言仍属于 fix4；校验通过不表示最终 93 场景的数字已被该清单覆盖。

旧 AI 交接、实施计划、逐轮进度和重复状态审计已从现行文档移除，可通过 Git 历史查询。论文原稿和原始审稿意见保留于[论文原件](../paper/originals/README.md)，比赛与演示见[原始材料](../materials/README.md)。
