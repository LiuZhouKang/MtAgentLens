## 1. 工作方法（不可妥协）

**信条：先可信，再通用；内核自持，边界生成。**

唯一不可妥协：内核/运行时观测到的事实不能静默损坏、静默丢弃、静默假装存在。

**「更深入，不是更大」**：先用不可辩驳的一手证据（内核/BTF、原始 wire、
agent 自己落盘的 sqlite、DB 行 SQL、bpftool、构建产物）把系统钉死，再以
「证明」为单位删改。每加一条能力，同时加一条能证明它存在的门；每删一条能力，
同时把预算降下来。

**动手前四问**：顶尖专家会做什么用户没要求的事？从哪些原始材料开始？
用什么具体方法（差分/蜕变/性质测试、确定性 oracle、独立解码、FPR+Wilson、
开销契约）？除了我和用户，什么能证明结果是对的？

原始材料优先级：内核 tracepoint/BTF → 原始 wire 字节 → `/proc`/`bpftool` →
agent 自己落盘的记录 → DB 行本身（SQL，而非 reader 代码）→ 上游规范 →
git 历史 → 构建产物。**禁止**用二手结论代替一手证据。

## 6. 陷阱（全部实际踩过）

1. **不要把会写文件的评审 agent 放在同一工作树**：会写探针/回写源文件；
   用隔离 clone 或只读工具，评审后查 `git status`。
2. **单引号/单括号切片 panic**：`token.len() < 2` 时 `[1..len-1]` 越界。
3. **内容 needle 的子串匹配会误报**：命令类 needle 用 shell 段首/包装命令匹配。
4. **凭据分类会让良性读取 Unsafe**：自身 HOME/项目 `.env` 不要分类为 Credential。
5. **FPR 采集会被本会话污染**：必须用 inode 副本 + 唯一 comm（见 3.3）；
   分母必须是 `observed=true`。
6. **collector 优雅关闭可能 >30s**：benchmark 30s 后 SIGKILL；部分 run 的
   intents/evidence 为 0 是“未观测”，不是“无告警”。
7. **DB 是 root 0600**：评测/统计用 sudo 只读副本。
8. **长任务写成 .sh 再执行**，绝不编辑正在运行的脚本。
9. **eBPF verifier 验证用** `printf '%s\n' 1 | sudo -S -p '' <cmd>`；
   本 harness 会拦截自身进程的文件类 syscall（bpftrace 同为 0）。
10. **产物在 `collector/build/`**，不是 `target/`。
11. **`local/` 与真实凭据绝不提交**；`local/git-backups/*.bundle` 含历史 key，
    不要推送。
12. **`frontend/out/` 被忽略但 `.gitkeep` 必须保留**（rust-embed 在干净 clone
    上要能 derive）。
13. **clean clone 用工作树快照**（`git ls-files -co`）；未跟踪但未忽略的文件
    会被包含，忽略文件不会。
14. **预算只许降**：clippy 167 / ignored 3 / home 0 / allow 49；任何图省事的
    `#[allow]` 都必须有理由并让总数下降。
