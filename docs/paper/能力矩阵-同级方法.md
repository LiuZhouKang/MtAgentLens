# 同级/相近方法能力矩阵（回应"缺少同级方法比较"）

> 用途：给 `软件学报` 修改稿 §1 表 1 与 §5.2 基线协议提供**可直接粘贴**的矩阵与文字。
> 事实口径：**核实** = 读过论文正文/源码/文档；**论文声称** = 仅在论文中声称，未独立验证；
> `UNVERIFIED` = 未能从一手来源确认。所有 URL 来自 `local/references/baseline-survey/`（2026-10-23）

> 未复现的方法**不得在论文中引用其任何性能数字**。

## 1. 能力矩阵（论文 §1 表 1 替换文本）

| 方法（venue） | 观测输入 | 分析单元 | 输出 | 代码/许可 | 在本基准的可复现性 | 本文中的角色 |
|---|---|---|---|---|---|---|
| **MtAgentLens（本文）** | eBPF OS 事件（进程/文件/网络/TLS 明文）+ 应用层消息 | run 级 + 图（agent/资源/边界） | `Safe/Unsafe/Uncertain`（唯一最终裁决）+ claim/traceback | 本仓库 | — | 被评估系统 |
| **AgentSentinel**（arXiv 2509.07764, 2025）[核实] | eBPF+LSM 探针事件 + agent client 送来的 chat messages；依赖 agent 侧集成 client | enforcement event + 依赖事件轨迹（进程树），逐敏感操作 | 放行/终止 + 审计结论 | 开源（`m4p1e/agent-sentinel`） | **B**：原方法需 agent 侧 client 与 Docker 隔离；本仓库只复现其**官方降级变体 `AuditWithoutTrace`**（无轨迹审计），必须标注"变体" | 同层对照（无轨迹变体），不得称为完整方法 |
| **AgentSight**（arXiv 2508.02736, PACMI'25）[核实代码/论文声称检测] | eBPF 边界追踪 + TLS 语义 | 事件/会话 | 观测、导出（OTel/SQLite）；论文声称二级 LLM 分析可检测注入/死循环/协调瓶颈 | 开源（`eunomia-bpf/agentsight`, MIT, v1.0.34） | **观测可跑；作为检测器不可直接复现**（发布物未发现内置分类器） | 同层观测参考/等轨迹来源；不引用其检测数字 |
| **GUARDIAN**（NeurIPS 2025, arXiv 2505.19234）[核实] | 时序属性图（节点=回复 embedding，边=轮次通信） | agent 级异常节点 | 异常 agent 分数 | 开源（MIT, PyG） | **B**：需重训；良性 run 仅约 20–26 条，检测目标为幻觉/错误传播而非安全攻击 | 图类方法作为限制说明 |
| **BlindGuard**（ACL 2026 Main, arXiv 2508.08127）[核实] | 有向 agent 图 + 对话 embedding（SentenceBERT） | agent 级异常 | 异常 agent 分数 → 定位攻击者 | 开源（Apache-2.0，含 checkpoint） | **B**：需重训；数据生成依赖 LLM 模拟管线；无 tool-call 日志入口 | 图类方法作为限制说明 |
| **MAStitch**（AAMAS 2026, DOI 10.65109/BMJZ4532）[核实] | MAS 配置 + 平台监控执行日志（按 agent 切 chunk） | **run 级**整条执行日志 | anomalous/benign + 分数 + 解释 | **未找到官方仓库**（`UNVERIFIED`） | **B′**：training-free、输入可映射，可按论文重实现（E8 的应用层基线候选） | 审稿意见要求的"文本+工具调用日志"同层基线 |
| **ADR（Uber, MLSys 2026 Industry）**（arXiv 2605.17380）[核实] | Agent 侧 Sensor 采集的 tool calls / results / 嵌套会话 | 会话级 + detector | `is_malicious` + confidence + tokens/cost | 部分开源（Apache-2.0；Explorer/Prevention 未开源） | **B**：需适配输入 schema、默认双模型异构 + 上下文服务；替换模型须标注 adapted | 与已发表完整应用层检测系统的对照（B2） |
| **LlamaFirewall / AlignmentCheck**（Meta, arXiv 2505.03574）[核实] | 原生 `Trace = List[Message]`（含 `tool_calls`） | 逐动作（最新动作是否偏离目标） | `ALLOW / HUMAN_IN_THE_LOOP_REQUIRED` + 0/1 | 开源（MIT，`pip install llamafirewall`） | **B**：零 GPU 但需把 `tool_calls` 拍平进 content；LLM API 成本随轨迹长度线性 | 应用层轨迹判定器的参考实现 |
| **R-Judge**（EMNLP 2024 Findings, arXiv 2401.10019）[核实] | `user / agent{thought, action} / environment` 交互记录 | 交互记录级 | 0/1 + 分析文本 | 仓库**无 LICENSE** | **A-**：training-free、纯 API；脚本与自带数据集强耦合，需转换器 | judge 协议参考（本仓库 `compare/rjudge/` 已固定该协议） |
| **提示级基线**（LLM Guard、Meta Prompt Guard 等）[核实/论文声称] | 仅提示词/响应文本 | 文本片段 | 风险分/标签 | 见各自仓库 | **A**（可直接跑） | 原三基线（信息量最小），但结论必须限定"观测层级" |

分级：**A**=直接可用；**A-**=training-free 但需转换；**B**=需重训/重写适配器；**B′**=论文级可重实现（无公开代码）；**C**=不可复现/用途不匹配。

## 2. 可直接粘贴的论文文字

### 2.1 §1 表 1 之后的说明（替换原文中对同层方法的一句话）

> 表 1 按"观测输入、分析单元、输出与可复现性"比较相近方法。需要强调的是，
> 这些方法不可直接与本实验的 TPR/FPR 并列：AgentSentinel 的完整方法要求 agent 侧
> 集成审计 client，本工作仅复现其官方无轨迹变体；AgentSight 的发布物是观测与导出系统，
> 未包含可直接评测的分类器；GUARDIAN/BlindGuard 以 agent 级异常为输出且需重训，
> 与本基准的 run 级标签不一致；MAStitch 与 ADR 属于 run/会话级的应用层检测，
> 本工作将其作为同层对照的候选，并按各自适配范围如实标注。表中"可复现性"指能否在
> 本基准上真实运行，不代表方法优劣。

### 2.2 §5.2 基线协议的补充段

> 除三个提示级基线外，本文报告两类同层对照：（1）**应用层轨迹基线**（同模型、
> 同输出契约，仅输入为工具调用日志），用于分离"信息量"与"观测层级"；
> （2）**公开方法对照**（按各自论文协议适配输入，若替换模型则标注 adapted）。
> 任何未被真实复现的方法只出现在能力矩阵与限制章节，**不引用其性能数字**。

### 2.3 §7 限制（可粘贴）

> 同层方法的复现受三项客观限制：其一，部分方法（如 AgentSentinel）要求 agent 侧
> 集成审计组件，与本基准"零插桩"的前提冲突；其二，图类方法（GUARDIAN/BlindGuard）
> 需要训练且以 agent 级异常为输出，与本基准 run 级标签不同构；其三，部分方法无公开
> 代码或许可（MAStitch 未找到官方仓库，G-Safeguard/AgentAuditor 之外的若干实现
> license 不明确）。因此本文只对**真正复现的对照**报告数字，其余以能力矩阵与
> 定性讨论呈现。
