## 3. ⚠️ 必读陷阱（踩过的坑）

1. **`collector/.cargo/config.toml` 设了 `target-dir = "build"`**
   ⇒ 产物在 `collector/build/{debug,release}/`，**不是 `target/`**。
   `target/` 是 8 月的旧二进制。**用错会拿到陈旧代码**（本会话因此误判过一次）。
   已修正 `Makefile`、`README.md`、两个 legacy 脚本的引用。

2. **eBPF 程序跑真实验证必须 sudo**：`SUDO_PW` 环境变量（用户提供），
   `printf '%s\n' "$SUDO_PW" | sudo -S -p '' <cmd>`。sudo 凭据缓存不稳，每次显式喂密码。

3. **`trajectory_runtime_events.seq` 是 per-session 的**，跨 session 按 `seq desc` 排序会拿到旧数据，
   必须按 `created_at`。

4. **`make tls_capture` 是假成功**（匹配到同名目录），要用 `make .output/bin/tls_capture`。

5. **Python 环境**：`env/.venv` 存在但**未装 pytest**（`pyproject.toml` 里是可选依赖）。
   验证 Python 逻辑可用纯 `assert` 脚本。

6. **`python3 -m pytest` 在系统 python 不可用**；写 pytest 测试没问题，但要说明如何运行。
