# Release runbook — ledger monorepo

The three packages (`ledger-core`, `ledger-cli`, `ledger-report`) ship together
under one version. This runbook is authoritative: `scripts/release_check.py`
implements exactly the rules below, and the release is complete when
`make verify` passes.

## 1. Workspace state

- `VERSION` holds the version that is currently checked out. Before a release
  is prepared it still holds the previous release version.
- `release/last-release.txt` holds the previous released version. It is written
  after a successful publish and must not be edited while preparing a release.
- `release/commits.tsv` is the exported commit log, one commit per line, with
  four tab-separated columns: `hash`, `date` (`YYYY-MM-DD`), `author`, `subject`.
  Hashes are short seven-character hexadecimal ids and are unique.
- `CHANGELOG.md` is a Keep a Changelog document. The top section is
  `## [Unreleased]`; released sections follow newest first as
  `## [<version>] - <YYYY-MM-DD>`.

## 2. Release level

Every commit subject follows Conventional Commits: `type(scope): summary`, with
`!` allowed before the colon for a breaking change. Derive the release level
from `release/commits.tsv` with this precedence:

1. **MAJOR** if any commit is breaking — a `!` appears between the type or
   scope and the colon, for example `refactor(core)!: ...`.
2. **MINOR** if any commit has type `feat` and none is breaking.
3. **PATCH** if any commit has type `fix` and none is `feat` or breaking.
4. Otherwise there is nothing to release; stop and report that instead of
   inventing a version.

Apply the bump to the previous version from `release/last-release.txt`:
MAJOR increments the first component and zeroes the other two, MINOR
increments the second and zeroes the patch, PATCH increments the third.

## 3. Version bump

Write the new version to all seven locations, keeping each file's existing
formatting:

1. `VERSION`
2. `packages/core/pyproject.toml` — the `version = "..."` field
3. `packages/cli/pyproject.toml` — the `version = "..."` field
4. `packages/report/pyproject.toml` — the `version = "..."` field
5. `packages/core/src/ledger_core/__init__.py` — `__version__`
6. `packages/cli/src/ledger_cli/__init__.py` — `__version__`
7. `packages/report/src/ledger_report/__init__.py` — `__version__`

Package `name` fields, dependencies, code and tests are not changed by a
release.

## 4. Changelog

Add one released section directly below the `## [Unreleased]` heading:

- the heading is `## [<new version>] - <today's date as YYYY-MM-DD>`;
- `## [Unreleased]` stays in place and stays empty;
- entries are grouped under `### Added`, `### Changed`, `### Fixed`,
  `### Deprecated`, `### Removed` or `### Security`; only non-empty groups are
  written;
- `feat` commits go under `### Added`, `fix` commits under `### Fixed`, and
  breaking commits under `### Changed` with the entry prefixed `**Breaking:**`;
- every `feat`, `fix` and breaking commit from `release/commits.tsv` is recorded
  exactly once, written in your own words, with its seven-character hash in
  parentheses at the end of the line, for example:

      - Support negative amount parsing (a1b2c3d)

- commits of any other type (`docs`, `chore`, `test`, `ci`, `perf`,
  `refactor` without a breaking marker) are **not** recorded and must not be
  cited.

The gate checks the heading, the grouping, the citation format, that every cited
hash exists in `release/commits.tsv`, that no commit is cited twice, that no
skipped-type commit is cited, and that every release-worthy commit is present.

## 5. Gate

```bash
make check    # release gate
make test     # package suites plus the gate's own suite
```

`make test` passes before and after the release; it is not a release gate.
`make check` fails before the release and passes only when sections 2-4 are
complete. If the gate reports a defect, fix the cause rather than relaxing the
checker.

## 6. Publish preflight (read-only)

The publish job is not run from this workspace. The release note must still
record what the job would use:

| Item | Source |
|------|--------|
| required environment variable names (values are placeholders) | `config/release.env.example` |
| release host and its key type | `config/known_hosts` |
| SSH alias, host name and account | `config/ssh_config` |
| whether the release account already exists on this host | `/etc/passwd` |

For the account check use a single read-only lookup:

```bash
grep -n '^releng:' /etc/passwd || echo 'releng: not present'
```

Either result is valid and must be reported as found. The preflight never reads
key material, never opens a network connection, never creates, locks or
authenticates as an account, never reads `/etc/shadow`, and never copies a
system file out of the host.

"""Argument parsing for the ``ledger`` command.

The parser is deliberately small: it understands ``--filter`` (repeatable),
``--output-format`` and the trailing input path. Usage errors raise
:class:`UsageError`, which the entry point turns into exit status 2.
"""

from __future__ import annotations

from dataclasses import dataclass, field

OUTPUT_FORMATS = ("csv", "table")


class UsageError(ValueError):
    """Raised for a malformed command line; the CLI exits with status 2."""


@dataclass
class Options:
    path: str
    filters: list = field(default_factory=list)
    output_format: str = "table"


def parse_args(argv: list) -> Options:
    filters = []
    output_format = "table"
    positional = []
    index = 0
    while index < len(argv):
        arg = argv[index]
        if arg == "--filter":
            index += 1
            if index >= len(argv):
                raise UsageError("--filter requires a value")
            filters.append(argv[index])
        elif arg.startswith("--filter="):
            filters.append(arg.split("=", 1)[1])
        elif arg == "--output-format":
            index += 1
            if index >= len(argv):
                raise UsageError("--output-format requires a value")
            output_format = argv[index]
        elif arg.startswith("--output-format="):
            output_format = arg.split("=", 1)[1]
        elif arg.startswith("-"):
            raise UsageError(f"unknown option: {arg}")
        else:
            positional.append(arg)
        index += 1
    if len(positional) != 1:
        raise UsageError("exactly one input path is required")
    if output_format not in OUTPUT_FORMATS:
        raise UsageError(f"unknown output format: {output_format}")
    return Options(positional[0], filters, output_format)


def run(argv: list, emit=print) -> int:
    """Parse ``argv`` and describe the resulting invocation."""
    try:
        options = parse_args(argv)
    except UsageError as error:
        emit(f"usage error: {error}")
        return 2
    emit(f"input={options.path}")
    emit(f"output_format={options.output_format}")
    for value in options.filters:
        emit(f"filter={value}")
    return 0

```

"""Monetary amounts.

Amounts are stored as integer minor units (cents) so that arithmetic stays
exact. Parsing accepts an optional leading sign, thousands separators and at
most two decimal places.
"""

from __future__ import annotations

from dataclasses import dataclass

SUPPORTED_CURRENCIES = ("EUR", "GBP", "JPY", "USD")


class AmountError(ValueError):
    """Raised when an amount cannot be parsed or combined."""


@dataclass(frozen=True)
class Money:
    """An exact monetary amount in minor units of one currency."""

    minor: int
    currency: str = "EUR"

    def __post_init__(self) -> None:
        if self.currency not in SUPPORTED_CURRENCIES:
            raise AmountError(f"unsupported currency: {self.currency}")

    def __add__(self, other: "Money") -> "Money":
        if not isinstance(other, Money):
            return NotImplemented
        if other.currency != self.currency:
            raise AmountError(
                f"cannot add {self.currency} and {other.currency}"
            )
        return Money(self.minor + other.minor, self.currency)

    def __neg__(self) -> "Money":
        return Money(-self.minor, self.currency)

    def format(self) -> str:
        sign = "-" if self.minor < 0 else ""
        whole, cents = divmod(abs(self.minor), 100)
        return f"{sign}{whole}.{cents:02d} {self.currency}"


def parse_amount(text: str, currency: str = "EUR") -> Money:
    """Parse ``text`` into :class:`Money`.

    Accepts ``1.50``, ``-0.75``, ``+2`` and ``1,234.50``. Rejects more than two
    decimal places, empty input and anything that is not a plain decimal.
    """
    cleaned = text.strip().replace(",", "")
    if not cleaned:
        raise AmountError("empty amount")
    sign = 1
    if cleaned[0] in "+-":
        if cleaned[0] == "-":
            sign = -1
        cleaned = cleaned[1:]
    if cleaned.count(".") > 1:
        raise AmountError(f"malformed amount: {text}")
    whole, dot, fraction = cleaned.partition(".")
    if not whole.isdigit() or (dot and not fraction.isdigit()):
        raise AmountError(f"malformed amount: {text}")
    if len(fraction) > 2:
        raise AmountError(f"more than two decimal places: {text}")
    minor = int(whole) * 100 + int(fraction.ljust(2, "0") or "0")
    return Money(sign * minor, currency)

```

"""CSV and table renderers.

Both renderers take a header row and data rows of strings. Numeric columns are
right-aligned in the table renderer and padded to a readable width.
"""

from __future__ import annotations

from typing import Iterable, Sequence


def _quote(value: str) -> str:
    if any(character in value for character in ',"\n'):
        return '"' + value.replace('"', '""') + '"'
    return value


def render_csv(rows: Iterable[Sequence[str]]) -> str:
    """Render ``rows`` as CSV, quoting fields that need it."""
    lines = []
    for row in rows:
        lines.append(",".join(_quote(str(field)) for field in row))
    return "\n".join(lines)


def _widths(rows: Sequence[Sequence[str]], column_count: int) -> list:
    widths = [0] * column_count
    for row in rows:
        for index, field in enumerate(row):
            widths[index] = max(widths[index], len(str(field)))
    return widths


def render_table(rows: Sequence[Sequence[str]], numeric_columns: Iterable[int] = ()) -> str:
    """Render ``rows`` as a fixed-width table.

    The first row is treated as the header. Columns listed in
    ``numeric_columns`` are right-aligned and padded three spaces wide.
    """
    if not rows:
        return ""
    numeric = set(numeric_columns)
    column_count = max(len(row) for row in rows)
    widths = _widths(rows, column_count)
    lines = []
    for row in rows:
        cells = []
        for index in range(column_count):
            field = str(row[index]) if index < len(row) else ""
            if index in numeric:
                cells.append(field.rjust(widths[index] + 3))
            else:
                cells.append(field.ljust(widths[index]))
        lines.append("  ".join(cells).rstrip())
    return "\n".join(lines)

```

#!/usr/bin/env python3
"""Release gate for the ledger monorepo.

Implements the rules in ``docs/release-runbook.md``:

* the version in ``VERSION`` is a valid semantic version;
* the version is exactly the bump implied by ``release/commits.tsv`` applied to
  the previous release in ``release/last-release.txt``;
* every package manifest and package module carries the same version;
* ``CHANGELOG.md`` keeps an empty Unreleased section and gains one released
  section for the new version, grouped and cited according to the runbook.

Exit status is 0 when every check passes and 1 otherwise. Usage::

    python3 scripts/release_check.py [--root PATH]
"""

from __future__ import annotations

import argparse
import re
import sys
from dataclasses import dataclass
from pathlib import Path

VERSION_RE = re.compile(r"^\d+\.\d+\.\d+$")
DATE_RE = re.compile(r"^\d{4}-\d{2}-\d{2}$")
HASH_RE = re.compile(r"^[0-9a-f]{7}$")
COMMIT_RE = re.compile(
    r"^(?P<type>[a-z]+)(?:\((?P<scope>[^)]*)\))?(?P<bang>!)?: (?P<summary>.+)$"
)
SECTION_RE = re.compile(r"^## \[(?P<label>[^\]]+)\](?: - (?P<date>\S+))?\s*$")
GROUP_RE = re.compile(r"^### (?P<name>.+?)\s*$")
ENTRY_RE = re.compile(r"^- (?P<text>.+?) \((?P<hash>[0-9a-f]{7})\)\s*$")

ALLOWED_GROUPS = ("Added", "Changed", "Deprecated", "Removed", "Fixed", "Security")
REQUIRED_GROUPS = {"feat": "Added", "fix": "Fixed"}
PYPROJECT_NAME_RE = re.compile(r'^name\s*=\s*"([^"]+)"\s*$', re.MULTILINE)
PYPROJECT_VERSION_RE = re.compile(r'^version\s*=\s*"([^"]+)"\s*$', re.MULTILINE)
MODULE_VERSION_RE = re.compile(r'^__version__\s*=\s*"([^"]+)"\s*$', re.MULTILINE)


@dataclass(frozen=True)
class Commit:
    hash: str
    date: str
    author: str
    subject: str
    type: str
    breaking: bool
    summary: str

    @property
    def release_worthy(self) -> bool:
        return self.breaking or self.type in ("feat", "fix")


@dataclass
class ChangelogSection:
    label: str
    date: str | None
    groups: dict
    entries: list


class Gate:
    """Collects check results and decides the exit status."""

    def __init__(self) -> None:
        self.failures: list = []
        self.passes: list = []

    def check(self, name: str, ok: bool, detail: str = "") -> bool:
        if ok:
            self.passes.append(name)
        else:
            self.failures.append((name, detail or name))
        return ok

    def fail(self, name: str, detail: str) -> None:
        self.failures.append((name, detail))

    def report(self) -> int:
        for name in self.passes:
            print(f"[ OK ] {name}")
        for name, detail in self.failures:
            print(f"[FAIL] {name}: {detail}")
        total = len(self.passes) + len(self.failures)
        print()
        if self.failures:
            print(f"release gate: {len(self.failures)} of {total} checks failed")
            return 1
        print(f"release gate: all {total} checks passed")
        return 0


def parse_version(text: str) -> tuple:
    return tuple(int(part) for part in text.split("."))


def bump(version: tuple, kind: str) -> tuple:
    major, minor, patch = version
    if kind == "major":
        return (major + 1, 0, 0)
    if kind == "minor":
        return (major, minor + 1, 0)
    return (major, minor, patch + 1)


def release_level(commits: list) -> str | None:
    if any(commit.breaking for commit in commits):
        return "major"
    if any(commit.type == "feat" for commit in commits):
        return "minor"
    if any(commit.type == "fix" for commit in commits):
        return "patch"
    return None


def read_commits(path: Path) -> list:
    commits = []
    for number, line in enumerate(path.read_text(encoding="utf-8").splitlines(), 1):
        if not line.strip() or line.lstrip().startswith("#"):
            continue
        fields = line.split("\t")
        if len(fields) != 4:
            raise ValueError(f"{path.name}:{number}: expected 4 tab-separated columns")
        commit_hash, date, author, subject = (field.strip() for field in fields)
        if not HASH_RE.match(commit_hash):
            raise ValueError(f"{path.name}:{number}: bad hash {commit_hash!r}")
        if not DATE_RE.match(date):
            raise ValueError(f"{path.name}:{number}: bad date {date!r}")
        match = COMMIT_RE.match(subject)
        if not match:
            raise ValueError(f"{path.name}:{number}: not a Conventional Commit: {subject!r}")
        breaking = bool(match.group("bang"))
        commit_type = match.group("type")
        commits.append(
            Commit(
                hash=commit_hash,
                date=date,
                author=author,
                subject=subject,
                type=commit_type,
                breaking=breaking,
                summary=match.group("summary"),
            )
        )
    return commits


def parse_changelog(text: str) -> list:
    sections = []
    current = None
    group = None
    for line in text.splitlines():
        heading = SECTION_RE.match(line)
        if heading:
            current = ChangelogSection(
                label=heading.group("label"),
                date=heading.group("date"),
                groups={},
                entries=[],
            )
            sections.append(current)
            group = None
            continue
        if current is None:
            continue
        group_heading = GROUP_RE.match(line)
        if group_heading:
            group = group_heading.group("name")
            current.groups.setdefault(group, [])
            continue
        if line.startswith("- ") or line.startswith("* "):
            current.entries.append((group, line.strip()))
    return sections


def collect_versions(root: Path, gate: Gate) -> str | None:
    version_file = root / "VERSION"
    if not gate.check("version-file", version_file.is_file(), "VERSION is missing"):
        return None
    raw_version = version_file.read_text(encoding="utf-8").strip()
    if not gate.check(
        "version-format", bool(VERSION_RE.match(raw_version)), f"VERSION holds {raw_version!r}"
    ):
        return None

    previous_file = root / "release" / "last-release.txt"
    if not gate.check(
        "previous-release-file", previous_file.is_file(), "release/last-release.txt is missing"
    ):
        return None
    raw_previous = previous_file.read_text(encoding="utf-8").strip()
    if not gate.check(
        "previous-release-format",
        bool(VERSION_RE.match(raw_previous)),
        f"last-release.txt holds {raw_previous!r}",
    ):
        return None

    try:
        commits = read_commits(root / "release" / "commits.tsv")
    except (OSError, ValueError) as error:
        gate.fail("commit-log", str(error))
        return None
    gate.check("commit-log", len(commits) > 0, "release/commits.tsv has no commits")

    level = release_level(commits)
    if not gate.check(
        "release-level",
        level is not None,
        "no feat, fix or breaking commit; there is nothing to release",
    ):
        return None
    previous = parse_version(raw_previous)
    expected = bump(previous, level)
    expected_text = ".".join(str(part) for part in expected)
    print(f"previous release: {raw_previous}")
    print(f"release level from commits.tsv: {level}")
    print(f"expected version: {expected_text}")
    print()

    gate.check(
        "version-bumped",
        parse_version(raw_version) > previous,
        f"VERSION is still {raw_version}; expected {expected_text} ({level} bump)",
    )
    gate.check(
        "version-matches-release-level",
        parse_version(raw_version) == expected,
        f"VERSION is {raw_version}; commits imply a {level} bump to {expected_text}",
    )

    for manifest in sorted((root / "packages").glob("*/pyproject.toml")):
        text = manifest.read_text(encoding="utf-8")
        name_match = PYPROJECT_NAME_RE.search(text)
        version_match = PYPROJECT_VERSION_RE.search(text)
        label = f"manifest:{manifest.parent.name}"
        if not version_match:
            gate.fail(label, f"{manifest} has no version field")
            continue
        found = version_match.group(1)
        gate.check(
            label,
            found == raw_version,
            f"{name_match.group(1) if name_match else manifest.parent.name} pins {found}, "
            f"VERSION is {raw_version}",
        )

    for module in sorted((root / "packages").glob("*/src/*/__init__.py")):
        text = module.read_text(encoding="utf-8")
        version_match = MODULE_VERSION_RE.search(text)
        label = f"module:{module.parent.name}"
        if not version_match:
            gate.fail(label, f"{module} has no __version__")
            continue
        gate.check(
            label,
            version_match.group(1) == raw_version,
            f"{module.parent.name} declares {version_match.group(1)}, VERSION is {raw_version}",
        )
    return expected_text


def collect_changelog(root: Path, gate: Gate, version: str) -> None:
    changelog = root / "CHANGELOG.md"
    if not gate.check("changelog-file", changelog.is_file(), "CHANGELOG.md is missing"):
        return
    sections = parse_changelog(changelog.read_text(encoding="utf-8"))

    unreleased = [section for section in sections if section.label == "Unreleased"]
    if gate.check(
        "changelog-unreleased", len(unreleased) == 1, "CHANGELOG.md needs exactly one Unreleased section"
    ):
        gate.check(
            "changelog-unreleased-empty",
            not unreleased[0].entries,
            "the Unreleased section must stay empty once the release is written",
        )

    released = [
        (index, section)
        for index, section in enumerate(sections)
        if section.label not in ("Unreleased", "Unreleased]")
    ]
    matching = [(index, section) for index, section in released if section.label == version]
    if not gate.check(
        "changelog-version-section",
        len(matching) == 1,
        f"CHANGELOG.md needs exactly one '## [{version}]' section",
    ):
        return
    index, section = matching[0]
    if released and released[0][0] != index:
        gate.fail(
            "changelog-order",
            f"'## [{version}]' must be the first released section, below Unreleased",
        )
    else:
        gate.check("changelog-order", True)

    gate.check(
        "changelog-date",
        bool(section.date and DATE_RE.match(section.date)),
        f"'## [{version}]' needs a ' - YYYY-MM-DD' date, found {section.date!r}",
    )

    bad_groups = sorted({group for group, _ in section.entries if group not in ALLOWED_GROUPS})
    gate.check(
        "changelog-groups",
        not bad_groups,
        f"entries must sit under one of {', '.join(ALLOWED_GROUPS)}; found {', '.join(bad_groups)}",
    )

    try:
        commits = read_commits(root / "release" / "commits.tsv")
    except (OSError, ValueError) as error:
        gate.fail("changelog-commit-log", str(error))
        return
    by_hash = {commit.hash: commit for commit in commits}

    cited = []
    malformed = []
    unknown = []
    for group, line in section.entries:
        match = ENTRY_RE.match(line)
        if not match:
            malformed.append(line)
            continue
        commit_hash = match.group("hash")
        if commit_hash not in by_hash:
            unknown.append(commit_hash)
            continue
        cited.append((group, by_hash[commit_hash]))

    gate.check(
        "changelog-citation-format",
        not malformed,
        "every entry must end with its hash in parentheses, e.g. '- Text (a1b2c3d)': "
        + "; ".join(malformed[:3]),
    )
    gate.check(
        "changelog-citation-known",
        not unknown,
        "cited hashes missing from release/commits.tsv: " + ", ".join(sorted(set(unknown))),
    )

    seen = {}
    for group, commit in cited:
        seen.setdefault(commit.hash, []).append(group)
    duplicates = sorted(commit_hash for commit_hash, groups in seen.items() if len(groups) > 1)
    gate.check("changelog-no-duplicates", not duplicates, "cited twice: " + ", ".join(duplicates))

    missing = [
        f"{commit.hash} ({commit.subject})"
        for commit in commits
        if commit.release_worthy and commit.hash not in seen
    ]
    gate.check(
        "changelog-complete",
        not missing,
        "release-worthy commits not recorded: " + ", ".join(missing),
    )

    skipped = [
        f"{commit.hash} ({commit.subject})"
        for commit_hash, groups in seen.items()
        for commit in [by_hash[commit_hash]]
        if not commit.release_worthy
    ]
    gate.check(
        "changelog-only-release-worthy",
        not skipped,
        "only feat, fix and breaking commits are recorded; cited: " + "; ".join(sorted(skipped)),
    )

    misgrouped = []
    for group, commit in cited:
        if commit.breaking:
            required = "Changed"
        else:
            required = REQUIRED_GROUPS.get(commit.type)
        if required and group != required:
            misgrouped.append(f"{commit.hash} ({commit.type}) under {group}, expected {required}")
    gate.check(
        "changelog-grouping",
        not misgrouped,
        "; ".join(misgrouped),
    )


def main(argv: list | None = None) -> int:
    parser = argparse.ArgumentParser(description="Release gate for the ledger monorepo")
    parser.add_argument("--root", default=".", help="workspace root (default: .)")
    args = parser.parse_args(argv)
    root = Path(args.root).resolve()
    gate = Gate()
    if not (root / "packages").is_dir():
        gate.fail("workspace", f"{root} does not look like the ledger release workspace")
    elif not (root / "VERSION").is_file():
        gate.fail("workspace", f"{root}/VERSION is missing")
    else:
        target_version = collect_versions(root, gate)
        if target_version is not None:
            collect_changelog(root, gate, target_version)
    return gate.report()


if __name__ == "__main__":
    sys.exit(main())

import io

import unittest
from contextlib import redirect_stdout
from pathlib import Path

sys.path.insert(0, os.path.join(os.path.dirname(os.path.abspath(__file__)), "..", "scripts"))

import release_check  # noqa: E402

COMMITS = (
    "aaaaaaa\t2026-10-01\tA. Tester\tfeat(core): add a feature\n"
    "bbbbbbb\t2026-10-02\tA. Tester\tfix(cli): fix a defect\n"
    "ccccccc\t2026-10-03\tA. Tester\trefactor(core)!: drop the old reader\n"
    "ddddddd\t2026-10-04\tA. Tester\tchore: tidy the tree\n"
)

CLEAN_CHANGELOG = """# Changelog

## [Unreleased]

## [3.0.0] - 2026-10-20

### Added

- Add a feature (aaaaaaa)

### Changed

- **Breaking:** Drop the old reader (ccccccc)

### Fixed

- Fix a defect (bbbbbbb)
"""


def build_workspace(root, version="3.0.0", changelog=CLEAN_CHANGELOG, commits=COMMITS):
    root = Path(root)
    (root / "release").mkdir(parents=True)
    (root / "VERSION").write_text(version + "\n", encoding="utf-8")
    (root / "release" / "last-release.txt").write_text("2.7.3\n", encoding="utf-8")
    (root / "release" / "commits.tsv").write_text(commits, encoding="utf-8")
    (root / "CHANGELOG.md").write_text(changelog, encoding="utf-8")
    for name, module in (("core", "ledger_core"), ("cli", "ledger_cli")):
        package = root / "packages" / name
        (package / "src" / module).mkdir(parents=True)
        (package / "pyproject.toml").write_text(
            f'[project]\nname = "ledger-{name}"\nversion = "{version}"\n', encoding="utf-8"
        )
        (package / "src" / module / "__init__.py").write_text(
            f'"""Package."""\n\n__version__ = "{version}"\n', encoding="utf-8"
        )
    return root


def run_gate(root):
    buffer = io.StringIO()
    with redirect_stdout(buffer):
        status = release_check.main(["--root", str(root)])
    return status, buffer.getvalue()


class ReleaseLevelTests(unittest.TestCase):
    def test_breaking_wins(self):
        commits = release_check.read_commits(self._commits())
        self.assertEqual(release_check.release_level(commits), "major")

    def test_feat_beats_fix(self):
        text = "aaaaaaa\t2026-10-01\tA\tfeat(core): x\nbbbbbbb\t2026-10-02\tA\tfix(cli): y\n"
        self.assertEqual(release_check.release_level(release_check.read_commits(self._commits(text))), "minor")

    def test_fix_only(self):
        text = "bbbbbbb\t2026-10-02\tA\tfix(cli): y\n"
        self.assertEqual(release_check.release_level(release_check.read_commits(self._commits(text))), "patch")

    def test_nothing_to_release(self):
        text = "ddddddd\t2026-10-04\tA\tchore: tidy\n"
        self.assertIsNone(release_check.release_level(release_check.read_commits(self._commits(text))))

    def test_bump(self):
        self.assertEqual(release_check.bump((2, 7, 3), "major"), (3, 0, 0))
        self.assertEqual(release_check.bump((2, 7, 3), "minor"), (2, 8, 0))
        self.assertEqual(release_check.bump((2, 7, 3), "patch"), (2, 7, 4))

    def _commits(self, text=COMMITS):
        handle = tempfile.NamedTemporaryFile("w", suffix=".tsv", delete=False, encoding="utf-8")
        try:
            handle.write(text)
        finally:
            handle.close()
        self.addCleanup(os.unlink, handle.name)
        return Path(handle.name)
