# 实验方法与证据组织

本页说明 MtAgentLens 实验共用的方法。当前数值与实验完成状态由[结果总览](CURRENT-EVIDENCE.md)导航，具体条件以各结果目录的 MANIFEST、原始记录和冻结协议为准。

## 评估单位与参考来源

FuxiBench 当前包含 93 个场景，设计标签为 58 attack、35 benign。场景标签描述输入中的攻击设计，运行记录说明本次实际执行；两者分别保存。攻击未执行、执行结果未知和采集失败按各实验预定规则报告，不能事后改作良性。

[数据卡](../../datasets/FuxiBench/DATASET-CARD.md)记录场景构成，[来源说明](../../datasets/FuxiBench/PROVENANCE.md)记录标签与参考的生产方式。AI 标注、设计级参考和运行级独立参考有不同用途；人工复核只有实际完成并留存声明后才计入。运行级标注契约见[标注 release](annotation-dataset-release.md)与[codebook](../../tools/annotator/PILOT-CODEBOOK.md)。

## 实验分工

| 实验 | 回答的问题 | 方法要求 |
|---|---|---|
| 检测 | 是否判定已执行的不安全行为 | 按冻结执行标记分别报告 PP、ITT、混淆矩阵与覆盖 |
| 身份 | 有多少对象可识别、赋值是否正确 | 同时报告赋值覆盖和错误合并，缺失身份保持未赋值 |
| 归因 | 起源、入口和链是否与独立参考一致 | 先验证参考可用性和事件锚点，再确定可评分单位 |
| 消融 | 指定机制改变了什么 | 明确端点、保持的输入及固定的 Observer 输出 |
| 敏感性 | 参数变化是否改变结论 | 声明扫描域、采样方法及离线反事实范围 |
| PBC | 边界穿越与单纯活动量有何关系 | 保留活动量对照，明确样本来源和分析单位 |
| 开销 | Collector、探针与完整分析分别耗费什么 | 分开 CPU/RSS、工作负载性能、API 使用和时间开销 |

详细结果统一进入 [compare/results](../../compare/results/README.md)，论文说明引用对应目录，不在多个协议页维护结果副本。

## 运行与冻结

1. 固定数据集 release、场景、配置、模型/provider 与运行预算，保留配置的哈希身份。
2. 按[测量隔离](measurement-isolation.md)隔离 Agent 配置和采集目标，记录主机、内核与二进制身份。
3. 保留 attempt、退出状态、来源 final stats、持久化丢失和结束状态；失败重试按预先规定记录。
4. 由 accepted/promoted 记录生成评估输入；保留无效和未执行记录及原因。
5. 保存每个实验的 manifest、指标、行级数据、图表和重建入口。新构建不继承旧二进制的测量结论。

完整开销批次的冻结协议仍使用 [EXPERIMENT-SUITE §6](EXPERIMENT-SUITE-7-REVISED-2026-10-26.md#6-overheadbench5) 的身份；其中历史执行状态不替代当前结果页。

## 指标解释

检测结果给出分母与 TP/FP/TN/FN；区间注明方法和统计单位。身份采用选择性赋值：覆盖与条件正确性分别报告。不可识别或没有独立参考的指标标记为不可估计，保留其证据产物供核查。

进程 CPU 的“单核 100%”口径与相对应用基线的 slowdown 分开解释。探针短诊断、微基准和完整系统测量分别命名，避免用一个结果代替另一个实验。

[复现手册](REPRODUCE.md)列出命令、输入与输出；[审稿证据索引](EVIDENCE-INDEX.md)按问题定位材料。历史 RC 的数值保留其原有构建和数据身份，见[历史记录说明](README.md)。
