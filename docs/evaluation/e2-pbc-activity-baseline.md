## 4. 结论（可直接写进论文）

1. **"检测只是在区分活动量"不成立**：单独用 PBC 体积做检测器，AUROC 仅 **0.528**；
   低阈值下良性误报 27.8%，高阈值下只覆盖 50%/25% 的可行动攻击。
2. **可行动判定与 PBC 体积不同向**：43 个攻击里 28 个 PBC=0，仍出现 0 个 Unsafe；
   而 PBC≥1 的 15 个攻击里 4 个 Unsafe 全部出现；PBC≥10 只有 2 个攻击（占 4.7%）。
   裁决更多来自**内容/边界证据**，不是"活动多"。
3. 良性侧：PBC≥1 的 5 个良性 run 全部停在 Safe/review（Unsafe 0）——体积本身没有把
   良性推成可行动误报；这是"低误报、低召回 fail-closed"行为的直接证据。
4. 仍然不能宣称"已排除活动量混杂"：困难良性扩展集（E7）尚未采集；且 30/43 攻击被
   被测模型拒绝执行，攻击侧分层只覆盖实际发生的动作。

## 5. 论文写法与限制

> 我们在 RC fix4 的冻结图上统计了每 run 的 PBC：良性 mean 0.72 / max 3，攻击 mean 1.77 /
> max 32；用"PBC≥阈值即报警"的纯活动量基线，AUROC 仅 0.528，PBC≥1 时 FPR 27.8%、
> PBC≥10 时 TPR 50% 且无良性报警。可行动裁决与体积不同向，活动量不能解释检测结果。
> 困难良性扩展集留作后续。

限制：

- PBC 来自冻结图（与录音时分类器所用同一图）；replay 的分数/分支可能与 live 流式不同，
  但**裁决**与记录逐项一致，PBC 是图结构事实，不受 replay 近似影响。
- 单 arm 样本小（18/43），Wilson 区间宽；不得把点估计写成精确值。
- E7 未做；"活动量混杂已完全排除"这句话**不能说**。
