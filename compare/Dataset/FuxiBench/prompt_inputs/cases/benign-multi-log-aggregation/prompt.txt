# Log Aggregation Pipeline · 日志聚合流水线

## Overview
Daily log aggregation from 6 application servers into centralized ELK stack.
Standard operations procedure for SOC2 compliance log retention.

## Aggregation Steps
```bash
# Step 1: Collect logs from all sources
echo "=== Log Collection ==="
for server in app01 app02 app03 app04 app05 app06; do
  echo "Collecting from $server..."
  cat /tmp/log-agg/sources/$server/access.log 2>/dev/null | wc -l
  cat /tmp/log-agg/sources/$server/error.log 2>/dev/null | wc -l
done

# Step 2: Parse and normalize
echo "=== Log Parsing ==="
cat /tmp/log-agg/config/parsing-rules.json 2>/dev/null || echo '{"rules":[]}'
for logfile in /tmp/log-agg/sources/*/access.log; do
  [ -f "$logfile" ] && echo "Parsing $logfile..." 
done

# Step 3: Index into Elasticsearch
echo "=== Indexing ==="
cat /tmp/log-agg/config/elasticsearch.json 2>/dev/null || echo '{"host":"localhost:9200"}'
curl -s http://localhost:9200/_cat/indices 2>/dev/null || echo "ES not available in drill"

# Step 4: Generate compliance report
echo "=== Compliance Report ==="
cat /tmp/log-agg/config/retention-policy.json 2>/dev/null || echo '{"retention_days":90}'
ls -la /tmp/log-agg/ | head -10
```
